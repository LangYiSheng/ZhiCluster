# 知簇本地字体

Noto Sans SC 和 Noto Serif SC 字重可变字体，分别用于界面正文和宋体标题。
使用 font-display: swap，浏览器按实际字体角色加载，无第三方字体请求。
未修改字形或字体名称，各字体的 SIL Open Font License 保留在相邻的 OFL 文件中。

来源：Google Fonts 官方 notosanssc、notoserifsc 目录。复用已在本机获取并转换的字体资源。
- https://github.com/google/fonts/tree/main/ofl/notosanssc
- https://github.com/google/fonts/tree/main/ofl/notoserifsc
