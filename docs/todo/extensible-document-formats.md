# 可扩展文档格式读取

支持用户指定的15个扩展名：pdf、docx、md、txt、pptx、xlsx、csv、html、htm、json、jsonl、doc、xls、ppt、epub。

当前读取链路已有统一sections/chunks与PDF原件预览，但parser分发、上传类型/MIME、前端accept/筛选存在重复白名单。本次改为统一格式注册表，每种格式提供校验、解析、标准MIME、预览方式与依赖能力。保留现有解析器外部接口和真实来源定位。

- PDF：原件预览及文本层解析；扫描PDF的OCR不在本次范围。
- Word/Markdown/纯文本：保留已有段落、行与标题结构。
- 幻灯片：逐页提取标题、正文、表格，来源定位到幻灯片。
- 表格/CSV：按工作表和有界行组读取，保留表名、行号和数据，不执行公式。
- HTML/HTM：提取可阅读正文与结构，不执行脚本、不加载网页资源。
- JSON/JSONL：校验结构，按记录或分组提取，保留记录定位。
- EPUB：按书籍spine顺序提取章节，不读取外网资源；损坏、加密内容给出明确原因。
- DOC/PPT：使用容器内LibreOffice与UNO离线转换，明确禁用宏执行和外链更新，临时用户目录与进程隔离，超时终止；保留原件，以结构文本阅读。
- XLS：使用只读解析器提取缓存值与工作表，不执行宏和公式。

前端通过后端能力列表统一上传、筛选、格式标签及依赖缺失提示；PDF保留原件画布，其余提供安全结构阅读和来源跳转，不承诺Office原版式还原。

验收要求：真实生成各类文件，逐格式经过上传、worker解析、阅读、中文关键词搜索、引用来源定位与原件下载；坏文件、伪装格式、压缩包膨胀和活动HTML内容覆盖专项测试。写入测试仅使用独立站点与`.data/test-runs/`目录。

已完成：15格式隔离端到端验收通过；2026-10-25用户确认后已更新常用`localhost:3000`，能力接口15种格式均可用，原有资料与模型配置核对保留。详见`docs/document-formats.md`及`docs/knowledge-workspace-redesign-validation.md`。
