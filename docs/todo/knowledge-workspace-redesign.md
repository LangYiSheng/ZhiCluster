# 知识库浏览与对话配置改造

以本次六张参考图及用户目标为验收依据，保留实际文件管理、解析、检索、引用和后台任务语义。

## 功能与验证边界

- 资料浏览：知识库图标、名称和描述置顶；当前目录文件夹与文件列表、面包屑、后退前进；根目录不递归展示全部文件。
- 搜索在资料面板内展开，类型、状态和标签筛选归入搜索；排序菜单提供更新、创建、大小、类型和名称。
- 添加菜单仅包含本地文件、本地文件夹和新建文件夹；目录上传保留相对层级，服务端校验相对路径。
- 知识库编辑保存名称、描述、图标、颜色及唯一嵌入模型；入库和查询采用相同配置，模型变更明确提示重建索引。
- 同一聊天连接可启用多个对话模型，输入区可选模型及快速/思考模式；后端验证所选模型并实际使用。
- 思考模式保留正文与工具交替的流式输出；过程默认压缩为一行，可展开查阅，不显示内部推理字段。
- 历史按所属个人知识库精确过滤；跨库检索不改变会话归属，新库历史为空，过期本地会话指针不会串库。
- 设置按小标签页组织，至少六套配色；保存前可预览整个页面和阅读文本，预览与已保存状态隔离。
- 统计展示真实全局或当前知识库文档、存储、索引、任务、对话等计数。

## 验收

后端迁移和真实接口测试、前端行为回归、类型检查、代码检查与生产构建；隔离浏览器场景覆盖桌面、窄屏和横屏，模型验证使用可控兼容服务，不依赖真实云密钥。日常知识库数据不用于写入验收。
