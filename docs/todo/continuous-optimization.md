# 持续数据驱动优化

开始日期：2026-10-24。用户授权持续寻找公开数据集、测试并改进检索、知识管理和文件夹管理，有显著改善时分批提交；用户说结束后整理最终报告。当前目标保持进行中。

## 工作边界

- 日常服务保持在 3000/8000，独立评估服务使用 13000/18000、独立数据库 25432 与独立上传/运行配置卷。
- 批量测试不调用用户保存的模型，不修改用户资料、模型配置或索引。公开数据原文、逐条结果及临时状态保存在忽略目录 `.data/`。
- 建立改前基线，使用同一数据和参数复测；区分关键词检索、真实向量检索和模型回答质量。
- 所有改动先经针对性行为验证，再运行相关回归；阶段提交只包含本轮代码、可复现脚本及验收说明。

## 循环

1. 使用 BEIR SciFact/NFCorpus 测英文检索，使用 CMRC2018 开发集测试中文来源定位；记录固定样本、下载校验和、Recall/MRR 与延迟。
2. 测试深层/大量目录、批量文档与标签列表；检查移动、重名、回收恢复、跨库隔离。
3. 修复拖放上传目标、隐藏选择和目录目标展示等实际交互问题，并在隔离站点验收。
4. 从失败样本及性能瓶颈中选择下一轮，不以单一绿色测试作为系统整体改善的证明。

## 首轮发现（待修复验证）

- 深目录后代展开重复扫描全树；文档列表逐条查标签。
- 拖放上传的目录与实际目标可能不一致；翻页后的隐藏选择可能继续参加批量操作。
- 英文停用词与词内子串可能挤占候选池，需要公开标注集测量。
