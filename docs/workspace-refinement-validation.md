# 控件、资料栏与任务中心验收

日期：2026-10-23，继续按浏览器批注调整现有 React 工作区，保留字体、配色及圆角风格。

## 本轮行为

- 单选、多选和下拉统一为共享组件。复选支持混合状态；下拉支持键盘、禁用选项、空字符串选项与关闭返焦。配色选择仍只用卡片边框表达选中状态。
- 资料栏位于 `main` 右侧并与其等高，不再重复显示“参考资料”标题行。多份资料保留标签，单份直接展示内容。窄屏限制键盘焦点在资料栏内，关闭后返回“浏览资料”。
- 历史每项只显示标题；新建对话为标题栏关闭按钮旁的小加号。
- 文档列表点击直接阅读，属性放入三点菜单。属性视图先显示摘要，活动任务直接展示，其余属性和处理记录默认折叠。隐藏页面不保留弹出菜单。
- 成功文档不显示“已就绪”；未处理、实际进度或需要处理的问题仍可见。进度来自后端 0–100 数值，不模拟增长。
- 新增 `/tasks` 任务页，集中展示错误、模型未配置、自动重试与手动重试、取消。部分完成的任务不会显示为成功 100%；手动重试清除旧阶段、错误、进度与租约。
- 异常、运行中和已完成筛选先在服务端执行，再取最近 200 条，避免旧错误被新完成记录挤掉。文档任务带可读名称；聊天任务只允许所属用户访问和控制。
- 任务中的“配置模型”直达设置的模型连接，已有草稿不会因定位而被清除。README 补充实际接口格式、向量维度、流式/JSON 能力及 Docker 宿主机地址说明。
