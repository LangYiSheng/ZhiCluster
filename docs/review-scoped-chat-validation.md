## 最终行为

- 外观只有“显示与配色 / 文字与阅读”一套标签，预览自动对应整页/阅读文本；草稿、保存、键盘及跨设置分类状态保留。
- 资料侧栏的更多和关闭按钮中心对齐，390窄屏点击区域互不重叠。移除输入框“基于某库”文字及查阅区的实现说明，历史卡片上下间距一致。
- 展开的查阅过程仅显示每轮实际范围、查询词圆角项、去重结果数；不同范围分组，direct同型，旧消息兼容读取，不输出内部步骤、耗时或提供方推理。
- 模型可以读取当前范围，分页查询允许的知识库、文件夹和标签，再选择更小范围搜索；原生工具与JSON规划均支持。SQL始终与用户原选范围取交集，空数组/非法筛选不能扩大范围，匹配方式变化也不能放宽原条件。资料后来移出窄目录、去掉标签或删除筛选资源时，旧候选和引用会失效。
- 导入联合生成摘要与标签建议；模型即使返回旧目录建议也会被剥离。接受旧建议同样不改变文档位置，标签保留人工已有内容。
- 整理可选标签、文件夹或两者。服务端保存模式及资源范围，在生成、编辑和审批各层约束操作。文件夹模式将相似内容归并，可把整理后及原本已空的目录列入方案；完整选择覆盖全库，部分选择限制在原目录树。清理是可取消、可撤销的软删除，执行当下检查目录及后代无文档，保护新增内容和回收站内容。
