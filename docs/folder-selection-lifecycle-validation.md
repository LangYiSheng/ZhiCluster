# 目录目标检索与保存上下文验收

日期：2026-10-24。沿用隔离评估站点，不修改日常资料和模型连接。

## 本轮复现

- 合法的根目录名 `研究 / 论文` 与 `研究` 下的子目录 `论文` 原先生成同样的移动选项标签，用户无法识别实际目标。
- 普通下拉一次渲染全部目录，只有完整路径前缀键盘匹配。6,000 层目录生成全部路径可累计 162,009,000 个字符；不能从树遍历成功推断移动选择器可用。
- 文档保存 A 的响应迟到时，无条件关闭当前弹窗，可删除 B 的新编辑草稿。知识库保存 A 的响应迟到时，无条件选择 A，可打断已经切到 B 的工作。两种延迟响应测试均先在原实现复现失败。

## 变更

目录目标增加独立搜索输入，按 NFKC 归一化的叶名或跨层路径词匹配。一次只构造、渲染前 100 个匹配目标与当前选择，完整目录索引仍可检索；提供匹配数和缩小范围提示，不把后部目录静默丢弃。选中目标在搜索变化时仍显示原名，根目录始终可选。自身子树在生成候选前排除。

完整路径只为当前显示的目标构造。路径片段含 `/`、双引号或反斜杠时使用可逆的引号展示，保留已有合法名称；例如字面根目录显示为 `"研究 / 论文"`，嵌套目标为 `研究 / 论文`。

文档操作携带提交时的表单实例，成功后只关闭对应表单。知识库保存携带编辑和所选库上下文，仅仍处于该上下文时自动选中新库；迟到成功仍刷新列表和报告保存完成，不关闭新草稿或强制切库。取消弹窗不会撤销已发出的保存请求，界面也不声称已撤销。

## 验证

- 目录选择 3 项：6,000 个目录只渲染 101 个初始选项（含根目录），按后部唯一叶名定位并提交正确 ID；区分分隔符名称；跨层检索、自身子树排除与根目标。
- 保存上下文 3 项：旧文档保存不关闭新草稿；旧知识库保存不抢占新库；正常创建仍自动选中新库。
- 完整前端回归 119 项通过，随后补的正常创建正向回归单独通过（与另 2 项上下文回归一起共 3 项通过）。TypeScript、ESLint 和生产构建通过。
- 真实浏览器 5 项通过，24.7 秒。新增目录搜索验证保留真实上传和副本流程，实际区分两个相同视觉路径、把文档移到正确嵌套 ID，并保留跨库拖放拒绝、外部移动选择清理、失效范围恢复、PDF/DOCX 与回收恢复。
