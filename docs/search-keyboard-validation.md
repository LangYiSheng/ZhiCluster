# 搜索输入与资料右键菜单交互验收

日期：2026-10-24。

## 复现与修复

搜索的三条新回归先在原代码全部失败：中文输入法确认候选的 Enter 打开已有结果；改词后 250ms 防抖期间 Enter 打开旧词来源；首条结果到达前按向下键使索引变成 -1，之后 Enter 无法打开首项。

搜索框现在对输入法组合输入及 229 键码跳过快捷操作；输入与请求词不一致或正在获取结果时，不展示或打开旧结果，显示等待状态。无结果时不生成负索引，结果缩短时选择索引限制在有效范围内。清空输入立即显示关键词空态，不沿用旧错误。

目录和文档原自绘右键菜单没有键盘焦点管理，Escape 无法关闭，透明遮罩会继续拦截鼠标。改为项目现有 Radix 体系的 ContextMenu，和三点菜单复用同一份动作内容及菜单项，删除重复自绘菜单和旧遮罩样式。支持键盘导航、Escape 返回原控件、外部点击关闭与视口边缘避让；资料区隐藏时关闭 Portal，返回后不重新打开。

使用 [Radix ContextMenu](https://www.radix-ui.com/primitives/docs/components/context-menu) 官方组件，新增该包 2.4.1，已有传递依赖保持不变。右键和三点菜单均明确 `modal=false`：独立探针确认旧模态菜单的焦点约束会把新 Dialog 的 autoFocus 输入框拉回旧菜单，最后落在关闭按钮；非模态菜单消除这一转场冲突。没有延迟业务操作，也没有增加模拟点击或全局焦点回调。

## 验证

- 三个搜索缺陷均有原实现失败、修复后通过的行为回归；搜索专项 6 项通过。
- 菜单专项 7 项通过：方向键与 Escape、两类菜单保留新 Dialog 的明确输入焦点、隐藏后不重开、两类外部点击和焦点、真实目录操作落到正确对象。
- 完整前端 140 项通过；TypeScript、ESLint 与生产构建通过。
- 后端本轮另有独立元数据生命周期修复，完整回归 384 passed / 56 skipped，真实 PostgreSQL 并发专项 26 项通过，见[元数据生命周期验收](metadata-lifecycle-validation.md)。

最终隔离 API 与前端组合的 7 项真实浏览器验收通过，41.7 秒。保留原上传/搜索/引用/回收流程，新增浏览器原生 Shift+F10 打开菜单、Escape 关闭且返回源文档按钮；320×640、844×390 菜单实际边界均位于视口内，截图保存在忽略目录 `frontend/test-results/context-menu-*.png`。

截图发现淡入动画的中间帧后，添加 opacity=1 的截图前置条件；工作区单流程重验通过，14.5 秒。人工查看两张最终菜单截图，背景、文字和边界正常。日常服务已在无活跃任务时更新，资料计数与模型配置 revision 保持不变。

独立探针还发现受控 Dialog 从菜单打开后关闭时可能落到 BODY，原因是原 Dialog 未注册返回目标；本轮不声称已修复这一独立焦点返回问题，保留下一轮验证。既有构建分块大小与 Settings act 警告继续单独记录。

后续收尾批次已补齐共享 Dialog 返回来源、失效来源区域 fallback 及异步删除 refetch 协调，见[弹窗焦点验收](dialog-focus-validation.md)。上段保留为当时验收范围，不代表收尾状态。
