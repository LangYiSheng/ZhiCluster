# 弹窗关闭与异步列表焦点验收

日期：2026-10-24。范围是当前共享 Dialog/Menu 与资料、知识库删除后的返回焦点，不是全站导航焦点系统。

共享菜单在打开时保存本次真实来源和所在区域，按菜单 Content DOM 保存在 WeakMap，避免使用全局“最近点击”。Dialog 按每次 Portal 打开周期捕获首次焦点入口，关闭后返回本次来源；来源已删除、禁用或隐藏时尝试同一资料区域。若其它弹窗或新资料栏已主动取得焦点，则保留该焦点。隐藏、inert、aria-hidden 和祖先 CSS 不可见目标均不可恢复。

知识库栏、工作区、参考资料栏与共享 Dialog Content 提供 `tabIndex=-1` 的稳定区域，不增加正常 Tab 停靠点。最后一项使嵌套弹窗中源按钮被删除时，仍可回到父弹窗。

真实浏览器额外复现了异步删除边界：确认弹窗关闭时先正确返回文档按钮，列表 refetch 随后删除该行，焦点才二次落到 BODY。资料操作和知识库删除现在等待原有 query invalidation 完成协调后，再按提交时的表单身份关闭；迟到的旧请求仍不能关闭新表单。没有引入任意延迟或 flushSync。

## 验证

- 共享 Dialog 14 项：三类来源、无 autoFocus 输入的两类确认、来源删除/禁用、hidden/inert/祖先 display:none、主动导航、再次打开、嵌套逐层返回及父来源删除。
- 元数据生命周期 5 项：额外以受控未完成 refetch 验证删除协调；既有迟到文档/知识库保存和删除身份检查保留。
- 完整前端 155 项通过；ESLint、TypeScript 和容器生产构建通过。
- 新增真实 API 浏览器流程检查普通按钮、三点、原生 Shift+F10、文档删除后的区域、知识库删除后的区域，以及 390×844 搜索打开参考资料的主动焦点。最终组合与既有工作区、资料完整性、任务验收一同运行，8项全部通过，49.6秒；输出目录 `frontend/test-results/final-acceptance/`。

初次新增用例中两条右键测试遗漏浏览器键盘模式事件，已修正测试模拟；未将它们计为产品缺陷。首次真实浏览器删除还焦失败推动了 refetch 协调修复，失败轨迹保留在忽略目录。原型还确认同一关闭 commit 中新页面 React autoFocus，以及部分双模态 Dialog 首焦形态有既有时序边界；本轮没有宣称覆盖这些尚未实现的显式导航交接。

既有 Settings act 警告、构建主分块超过 500KB 的提示仍存在，未把它们改成静默。
