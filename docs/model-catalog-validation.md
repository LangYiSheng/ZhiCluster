# 模型列表与独立选择验收

日期：2026-10-23。

## 行为

模型连接页的聊天和向量卡片各自管理目录状态。填写有效地址和 Key 后停顿约 800ms 自动获取，可手动刷新；选模型不会重复获取。当前模型不在目录时保留当前值，不自动选择第一项。不提供目录、空列表或请求失败时，仍可切换手动填写。

新增 `POST /api/settings/models`，按 `scope=llm|embedding` 使用所选草稿，后端只发送兼容的 `GET /models`，不请求生成、不保存配置。返回去重排序的 ID，不凭名称猜测聊天或向量能力。已有密钥在原地址可由后端复用，更换地址时必须提供对应密钥。目录请求不跟重定向，限制读取体积和超时，错误不回显上游响应正文。

地址、Key、清除密钥、保存版本变化会使旧列表失效；取消请求并检查请求代次，阻止迟到成功或失败覆盖新状态。离开模型连接分类会取消请求，草稿及手动填写模式保留。列表和密钥不进入浏览器持久存储。

协议根据 [OpenAI List models 官方文档](https://developers.openai.com/api/reference/resources/models/methods/list) 核对：`Authorization: Bearer ...`，响应 `data:[{id,...}]`；当前接口没有标准用途分类字段。
