# 知识工作区 UI 轻量打磨

日期：2026-10-24。

用户希望参考腾讯 ima 等同类产品，小幅改善成熟度。本轮查看了 [ima 官方展示页](https://ima.tencent.com/download) 和知簇实际页面，借鉴清楚的导航、内容层级与克制留白；保留知簇米白、墨绿和品牌衬线标题，没有复制品牌素材或引入新的产品模块。

## 界面调整

- 主导航、当前知识库、文件夹与工具页使用一致的浅墨绿选中态，与中性悬停态区分，深色主题同步处理。
- 文档页顶部图标从 62×66 收至 48×52；知识库标题使用 22px、600 字重的界面字体，收紧头部留白，保留品牌和聊天欢迎标题的字体选择。
- 筛选与标签管理控件统一至至少 32px；列表行略收紧，分隔线减轻，勾选后的浅底色在悬停时仍保留。
- 输入框聚焦时增加轻微边框和外圈反馈；移动端仅显示来源核实提示，避免展示不适用的键盘说明。尊重减少动态效果偏好。
- 文件类型图标保留各类型色，以当前画布混色；深色模式不再显示固定亮底色。

## 同轮交互修复

目录搜索输入中的普通 Enter 不再隐式提交外层移动表单，输入法组合输入保持原行为。聊天提交记录实际发送的文本，迟到成功回调只清理相同草稿。持久化配额满时记录失败写入前的存储值和写入标记，允许清理自己的旧存储；其他实例重新保存的同文稿、不同新稿和较新的内存稿均保留。

## 验证

- 前端全部 129 项测试通过，TypeScript、ESLint、生产构建通过。
- 草稿 hook 覆盖配额满、跨实例新稿、失败写入后外部新稿、较新内存稿、新实例重新保存旧文值和存储完全禁用六种场景；最终草稿、聊天与整理审阅定向回归 24 项通过。
- 隔离站点 `http://127.0.0.1:13000` 的 7 项真实浏览器流程通过，35.9 秒，包含上传、重复副本、目录落点、跨库拒绝、搜索、引用、PDF/DOCX、恢复和任务列表。
- 最终写入标记补丁后重建前端，并复验 3 项真实工作区流程通过，18.0 秒；新增 1440 深浅色文档截图，900 文档截图等待过渡结束后重取。人工查看这三张最终截图，布局和类型色正常。
- 现有响应式验收覆盖 1440×900、1100×800、900×780、390×844、844×390、320×640；浅色和深色均有实际截图。人工查看了本轮 390 聊天、1440 深色与带阅读侧栏布局，未见溢出。900 截图曾捕到侧栏过渡中间帧，已将该截图前置条件改为等待工作区左缘稳定到 56px。未声称所有主题与尺寸组合都逐一验收。

截图位于忽略目录 `frontend/test-results/`。前端构建仍提示一个分块超过 500 kB，Settings 测试仍有既存的 act 警告，本轮未将其列为已解决问题。测试只使用隔离库和受控响应，没有额外调用真实模型。
