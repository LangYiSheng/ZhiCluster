# 工作区界面整理验收

日期：2026-10-23。沿用现有 React 19 + TypeScript，实现于当前工作区。

## 本次调整

- 设置各分类统一为无衬线标题、分组卡片和字段网格；聊天与向量模型各自成组，同页编辑和独立测试。配色通过卡片边框显示选择，保留原生单选的键盘操作。
- 删除工作区页脚、设置导航品牌文案、底部安全说明、欢迎区配置提示、顶部私有标识、个人空间展示、侧栏搜索与主题快捷按钮。
- 顶部搜索左侧新增历史入口，卡片选择会话；新建、重命名、删除均在历史面板中操作，移除原会话下拉工具栏。
- 标签归入文档展示、列表筛选及管理弹窗，保留颜色、别名与版本更新；回收站固定在侧栏底部。
- 问答范围统一成分组弹窗；取消当前知识库时清除其文件夹和标签范围，已有会话范围保持只读。全局使用统一的主题滚动条。
- 聊天和资料区隐藏时关闭弹层，返回保留草稿与筛选。切换会话只断开页面事件订阅，不取消后台生成。
- 上传结果改为文档区底部折叠记录，失败时展开，避免浮层遮挡文件复选框及拖放操作。
