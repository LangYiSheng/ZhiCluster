# 工作区布局验收

日期：2026-10-23。基于用户提供的五张参考截图调整布局，保留现有字体、配色、圆角与主题。

## 页面与交互

- 聊天空态将欢迎和输入区一起居中；有内容时仍保留正文阅读宽度。
- 历史与问答范围使用同一个 Radix 非模态 Popover，分别锚定顶部历史按钮和输入区范围按钮，不渲染遮罩或锁定整个页面。保留内部滚动、屏幕边缘避让、外部点击关闭及 Escape 焦点还原。
- 聊天右侧资料工作区默认收起；按需打开资料管理、文档详情、正文或引用。同一文档只占一个标签，重复引用会重新定位；多份内容显示可切换、可关闭标签，单份内容不显示标签栏。关闭最后一份恢复聊天宽度。
- `/document` 是完整文档管理页面，库标题和上传操作在顶部，文件夹导航与宽行文件列表分别滚动。保留真实上传、文件夹、标签、批量管理、筛选排序、拖放与原件下载。
- `/trash` 是独立回收站，入口在设置上方；支持恢复文档、文件夹及知识库。没有活跃知识库时仍可恢复已删除知识库。
- 智能整理的前端入口与页面已撤下，旧 `/agent?kb=...` 地址替换跳转到对应知识库的聊天。保留后台流程和既有数据。
- 聊天草稿、运行中的对话订阅与资料标签在正常页面切换时保留；切换知识库会清理旧资料工作区。切页和关闭资料栏会使迟到的引用请求失效，避免重新打开已关闭内容或把用户导航走。
- 隐藏引用标签的正文可以后台加载，仅在标签激活后执行引用定位。小屏资料面板从右侧展开，左侧导航遮罩覆盖资料面板。
