# 引用预览与根目录验收（2026-10-26）

引用编号与来源列表支持悬停和键盘聚焦预览，显示文件名、真实引用片段、文件格式与所属知识库。卡片不发起模型或正文请求；点击仍打开原阅读器。失效来源不展示旧名称、片段或知识库。

移除“未分类”入口及遗留回调，界面统一使用“知识库根目录”。根目录拖入文件的 `folder_id` 为 `null`；当前子目录拖入保留对应目录，文件夹导入保留相对层级。查询用 `root` 哨兵保持兼容，无数据迁移。
